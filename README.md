# Minigame 1
## Devlog
When making Minigame 1, it involved components, Game objects and scenes to make the game come to life. A metaphor you can use to explain how each item complements each other can be like a lock and a key for example. I say this since a key doesn't hold much purpose unless it has a lock that complements it to open. Since a game object needs components and a scene needs game object its like saying to get this to work you need this much like how you need a key to unlock a lock. Each thing can live seperately but to get it to work it needs each other in order to complement one another. To make the whole scene stand out you need to add items like spikes in the game or coin to pair well with each other. Another way you can look at it is if they're a group working together to get a job done. In this case each part to making a game needs complementary parts to make it all come together.
